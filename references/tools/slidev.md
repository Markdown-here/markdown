# Slidev

## Summary

Write presentation slides in Markdown, with Vue components, live code, and presenter tools. Exports to PDF, PowerPoint, and PNG, or deploys as a website.

The most powerful option for developer talks. Not chosen for [Markdown 101](../../course/markdown-101/) because each deck is a Node project with a build step, and the extra syntax is more than a beginner course needs. [Marp](marp.md) was chosen instead.
