# reveal.js

## Summary

The longest-running HTML presentation framework, with a large plugin ecosystem and almost unlimited layout control. Slides can be written in Markdown through its Markdown plugin, but the deck itself is an HTML page, so the source isn't plain Markdown.

## Why not for Markdown 101

- The source is HTML with Markdown inside, so it doesn't read cleanly on GitHub or in OneDrive.
- PDF export goes through the browser's print view or a separate tool such as DeckTape. There's no PowerPoint export.
- More setup and styling than [Marp](marp.md) for a 30-minute course.

## Ways to use it from Markdown

- [Quarto](quarto.md) renders Markdown to a reveal.js deck.
- [reveal-md](https://github.com/webpro/reveal-md) serves a Markdown file as a reveal.js deck from the command line.
- [vscode-reveal](https://github.com/czhiling/vscode-reveal) previews a Markdown file as a reveal.js deck in VS Code.
