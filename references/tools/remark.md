# remark (slideshow)

## Summary

A small in-browser slideshow tool: Markdown goes in a `<textarea>` in one HTML file, and remark turns it into slides. Simple and long-lived, but little active development. Not to be confused with the unrelated `remark` Markdown processor in the unified ecosystem.
