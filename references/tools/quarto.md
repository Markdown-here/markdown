# Quarto

## Summary

A publishing system built on [Pandoc](pandoc.md). It turns Markdown (`.qmd`) into documents, websites, books, and presentations. Presentations can be [reveal.js](reveal-js.md), PowerPoint, or Beamer. It has a VS Code extension.

## Why it's the runner-up for Markdown 101

- Its PowerPoint output is native and editable, unlike [Marp](marp.md)'s default image-per-slide `.pptx`. It can also use a corporate `.pptx` template.
- But it needs the Quarto CLI installed, and the source uses Quarto-specific syntax. That's more to explain than Marp's "`---` between slides".
- Strong fit later for docs-as-code, where one Markdown source has to become a website, a PDF, and slides.
