# Markdown 1.0

## Summary

Markdown leaves beta: what changed since the first release, and the first ports to other languages.

## Key takeaways

- Dropped the experiment of GPL plus a paid commercial license: confusing and unsuccessful.
- Code blocks simplified: any line indented 4 spaces or 1 tab.
- Unordered lists can use `*`, `+`, or `-`.
- Markdown is two things: a syntax for writers, and the Perl tool that converts it.
- Early ports: Michel Fortin's PHP Markdown (bundled with WordPress), xMarkdown, and Drupal and Moodle integrations.
