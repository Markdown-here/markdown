# The Eternal Truth of Markdown

## Summary

A witty essay arguing that Markdown won because it built on how people already wrote plain text, and exploring the problems that came with putting Markdown in everything.

## Key takeaways

- Markdown is probably the most widely used markup on the web; nearly every text box supports it.
- It succeeded where reStructuredText and Setext didn't by adopting existing email and forum conventions instead of inventing new syntax.
- Its core assumption: plain text is the best long-term storage format.
