# Markdown & YAML Cheat Sheet

## Summary

A one-page cheat sheet covering Markdown basics and the YAML you need for frontmatter.

## Key takeaways

- YAML: indent with two spaces; `key: value` pairs; `- ` for list items.
- `>` folds a multi-line string into one line; `|` keeps the line breaks.
- Quote strings when in doubt to avoid escaping surprises.
- YAML at the top of a Markdown file adds structured data: frontmatter.
