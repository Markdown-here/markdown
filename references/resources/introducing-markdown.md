# Introducing Markdown

## Summary

Gruber's announcement of Markdown: a text-to-HTML tool that lets web writers use a readable plain-text syntax.

## Key takeaways

- Released as a plug-in for Movable Type and Blosxom, and as a standalone Perl script (usable as a BBEdit text filter).
- Originally licensed under the GPL.
- Came with a syntax page and an online demo, the Dingus.

## Quotes

> So, yes, before another person asks, it is sort of like Textile. Except that it's different.
