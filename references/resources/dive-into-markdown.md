# Dive Into Markdown

## Summary

An essay on why Markdown is forgiving: [Gruber](../people/john-gruber.md) explains how a debate over strict XML feed parsing changed his mind, and why Markdown deliberately accepts imperfect input instead of failing on it.

## Key takeaways

- Opens by asking when you last changed your mind because of an argument.
- Contrasts Postel's Law (be liberal in what you accept) with XML's rule that parsers must stop on fatal errors.
- Markdown is meant to be felt as much as reasoned about: it should feel natural to write.
