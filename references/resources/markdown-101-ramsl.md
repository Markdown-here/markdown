# Markdown 101

## Summary

A short introduction to Markdown that's mostly valuable as a list of links: online and offline editors, Pandoc and other converters, and what people build with Markdown, such as slides, résumés, and documentation sites.

## Key takeaways

- Markdown is a *writing* format; HTML is a *publishing* format.
- Markdown's pitch over word processors: more efficient, faster, platform-independent, and versatile.
- Ordered and unordered lists can be combined in one list.
- Markdown is used well beyond notes: slideshows (remark, mdp, landslide), résumés (HackMyResume), and documentation sites (MkDocs, daux.io).

## Quotes

> While HTML is a publishing format, Markdown is a writing format
