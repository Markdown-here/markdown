# Opening .md files on Android

## Summary

My fix for Android refusing to open `.md` files in a Markdown editor.

## Key takeaways

- On a Samsung phone, tapping a `.md` file offered no useful app, and opening it from Writer Plus didn't work.
- Fix: use the MiXplorer file manager, then **Open as** to choose any installed editor.
