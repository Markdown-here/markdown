# Slidev vs Marp vs reveal.js: code-first presentations (2026)

## Summary

A PkgPulse comparison of the three main ways to write slides as code. The quick rule: [Slidev](../tools/slidev.md) for technical talks with live code and Vue components, [Marp](../tools/marp.md) for the simplest pure-Markdown decks with PDF and PowerPoint export, and [reveal.js](../tools/reveal-js.md) for full HTML control and plugins.

The source for choosing Marp for [Markdown 101](../../course/markdown-101/).

## Key takeaways

- Slidev is the most powerful for developer talks, but it's a Node and Vue project.
- Marp is the least interactive, and the easiest: one Markdown file and a VS Code extension.
- reveal.js is the most customizable, with an HTML source.
- Versions checked: `@slidev/cli` 52.15.2, `@marp-team/marp-cli` 4.4.0, `reveal.js` 6.0.1.
