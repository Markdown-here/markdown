# Learning Markdown

## Summary

A MakeUseOf guide to Markdown for people who write for the web: the basic syntax, a few MultiMarkdown extras, automation shortcuts, and a tour of editors by platform. Fun, but many of the apps it recommends are gone.

## Key takeaways

- Markdown is faster than writing HTML and better suited to the web than Word.
- You can write Markdown in any plain-text editor, even Notepad, and preview or export it elsewhere.
- MultiMarkdown, by Fletcher Penney, adds tables, footnotes, and more.
- Hard line break: end a line with two or more spaces.
- Text expanders and macro tools (TextExpander, Keyboard Maestro) can type Markdown syntax for you.
- Pick an editor with live preview when you're learning.
