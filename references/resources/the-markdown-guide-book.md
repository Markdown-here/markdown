# The Markdown Guide

## Summary

The book version of the Markdown Guide website: what Markdown is, how it flows from text file to HTML, where it's used (websites, docs, notes, books), and the basic and extended syntax with compatibility advice.

## Key takeaways

- Markdown syntax is designed to stay readable even when it isn't rendered.
- The process: write a `.md` file, open it in a Markdown app, convert to HTML, view it or export to another format.
- Almost every app implements a slightly different version of Markdown. These are called flavors.
- For compatibility: use asterisks, not underscores, for emphasis inside a word; put blank lines around blockquotes; put pipes at both ends of table rows.
- Trailing-space line breaks are hard to see; a backslash works in CommonMark but not everywhere.
- Docs tooling built on Markdown: Read the Docs, MkDocs, Docusaurus, VuePress, Jekyll (free hosting on GitHub Pages).
- Extended syntax: tables, fenced code blocks, footnotes, heading IDs, definition lists, strikethrough, task lists, emoji.

## Quotes
