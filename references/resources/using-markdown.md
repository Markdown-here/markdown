# Using Markdown

## Summary

A thorough, friendly walkthrough of the original Markdown syntax, from an author who caught the Markdown bug restoring old texts. Strongest on links (inline, reference, and automatic) and on the editors the author actually uses.

## Key takeaways

- Gruber created Markdown; Aaron Swartz was its beta tester and contributor.
- Markdown makes prose easier to read, write, and edit. It's a writing format; HTML is a publishing format.
- Two heading styles: setext (underlined, only two levels) and atx (`#`, six levels). Prefer atx.
- A blank line makes a new paragraph; two trailing spaces make a line break.
- Reference-style links keep paragraphs readable: `[text][id]` in the paragraph, `[id]: url` elsewhere.
- Link labels aren't case-sensitive, and `[text][]` uses the text itself as the label.
- Host your own copy of images rather than hot-linking someone else's.
- Editors the author uses: Ghostwriter (Windows, Linux), Typora and Caret (cross-platform), Sublime and Atom for code.
- Beyond Markdown: MultiMarkdown, Pandoc, Fountain (screenplays), CriticMarkup (review marks).
