# Marcia, Marcia, Markdown

## Summary

A release note for Markdown 1.0b4, and the first pointer to going the other way: HTML back to Markdown with Aaron Swartz's html2text.

## Key takeaways

- html2text turns HTML into readable plain text that happens to be valid Markdown.
- Round-tripping Markdown → HTML → Markdown can't give back exactly the same document, but it comes close.
- Markdown and html2text were usable from the Mac OS X Services menu via HumaneText.
