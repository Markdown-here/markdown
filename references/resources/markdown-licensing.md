# Markdown Licensing

## Summary

Why Markdown moved from the GPL to a BSD-style license in version 1.0.1, plus Gruber's wish list for 1.1.

## Key takeaways

- The GPL stopped BSD-licensed open source projects from including Markdown, which was the opposite of what Gruber wanted.
- Nobody paid for a commercial license anyway.
- The BSD-style license asks only for credit and that you don't use the name "Markdown" without permission.
- Tip: add `.text` to any Daring Fireball article URL to see its Markdown source.
- Wish list for 1.1 included tables and definition lists, which later arrived through other flavors, not Gruber's.
