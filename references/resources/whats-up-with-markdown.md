# What's Up With Markdown

## Summary

Markdown from a Microsoft 365 point of view: where it already shows up across [Microsoft](../organizations/microsoft.md)'s products, and why it isn't a single standard.

## Key takeaways

- Markdown works in Teams chat, the SharePoint Markdown web part, Adaptive Cards, Power Automate approvals, Bot Composer, and QnA Maker.
- Nearly every GitHub repo starts with a `README.md`.
- Markdown isn't a formal standard. SharePoint's web part uses the Marked syntax; GitHub uses GFM.
