# Professional Markdown

## Summary

A short book for developers covering flavors, parsers, syntax, and tools. Thin overall, but it has a clear explanation of table column alignment.

## Key takeaways

- Flavors: CommonMark, and GitHub Flavored Markdown (also used by GitLab and iA Writer).
- A parser converts Markdown to HTML: markdown-it in the browser, Pandoc on the server.
- Babelmark compares how many parsers render the same input. Babelmark 2 is unmaintained; use Babelmark 3.
- Align table columns with colons in the divider row: `:---` left, `---:` right, `:---:` centered.
- Also covers reference links, footnotes, and definition lists.
