# Markdown Dreams

## Summary

A practical survey of Markdown tooling from a working documentation writer, with the most useful part being a breakdown of the kinds of Markdown editors and a platform-by-platform list of them.

## Key takeaways

- Four kinds of editor: dedicated Markdown editors, code editors, general text editors, and browser-based tools.
- For documentation or other big writing projects, install a dedicated editor; developers can stay in their code editor.
- Static site tools like Hugo and MkDocs add their own extensions on top of Markdown (shortcodes, Python-Markdown Extensions).
- Editors called out: Typora (WYSIWYG), Joplin (notes and to-dos, syncs to OneDrive), Ghostwriter, iA Writer, Byword, Caret, MacDown.
