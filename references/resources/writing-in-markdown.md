# Writing in Markdown

## Summary

A short, opinionated guide for writers. Best known for its suggested style rules, which are a great starting point for a team style guide.

## Key takeaways

- Markdown is two things: a plain-text formatting syntax, and a tool that converts it to HTML and other formats.
- You've probably already used Markdown: \*emphasis\*, hyphen lists, and lines of asterisks are all Markdown.
- Many flavors (Kramdown, Redcarpet, Maruku, Discount) were inspired by PHP Markdown Extra.
- Suggested style: `_italic_` and `**bold**`; atx `#` headings; blank lines around headings, list items, and rules; meaningful labels on reference links; Markdown over raw HTML whenever possible.

## Quotes

> Markdown is logical, simple, and uses just a few punctuation symbols to format text
