# CommonMark Ready Reference

## Summary

A compact reference on [CommonMark](../organizations/commonmark.md): why the original Markdown needed a proper spec, and how to build and run the `cmark` reference implementation yourself on Linux and Windows.

## Key takeaways

- The original Markdown had no well-defined spec, so implementations based on the Perl script disagreed.
- CommonMark keeps Markdown but states its rules unambiguously for implementers; sites like Stack Overflow adopted it.
- The reference implementation, `cmark`, is written in C and is very fast.
- You can build `cmark` from source for Linux, and cross-compile a Windows `cmark.exe` with MinGW.
