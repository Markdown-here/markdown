# Unordered Lists in Markdown

## Summary

Why Markdown allows three bullet characters, and which ones people actually use.

## Key takeaways

- `*`, `-`, and `+` all work because Gruber couldn't pick one in 2003, and still can't.
- His Twitter poll: 54% hyphen, 42% asterisk, 4% plus.
- The missing option is a real bullet (•), left out because non-ASCII characters were unreliable back then.
