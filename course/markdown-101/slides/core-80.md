## The core 80%

These work almost everywhere: GitHub, VS Code, notes apps, slides.

| | |
|---|---|
| Heading | `# Title` |
| Bold, italic | `**bold**`, `*italic*` |
| List | `- item`, `1. item` |
| Link | `[text](url)` |
| Image | `![alt](image.png)` |
| Code | `` `code` ``, three backticks |
| Quote | `> quote` |
| Divider | `---` |
