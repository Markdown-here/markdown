## Same characters, different result

| You type | Markdown | Chat apps |
|---|---|---|
| `*hello*` | *hello* | **hello** |
| `_hello_` | *hello* | *hello* |
| `` `hello` `` | `hello` | `hello` |
| A table | a table | plain text |

Each app has its own **flavor**. Many chat apps use their own shortcuts, not real Markdown.
