## Same characters, different result

| You type | Markdown | Teams chat |
|---|---|---|
| `*hello*` | *hello* | **hello** |
| `_hello_` | *hello* | *hello* |
| `` `hello` `` | `hello` | `hello` |
| A table | a table | plain text |

Each app has its own **flavor**. Teams has chat shortcuts, not real Markdown.
