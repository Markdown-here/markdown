A 30-minute, hands-on course. By the end you can write a clean README, meeting notes, or chat message in Markdown, and you know where to learn more.

**You need** any editor with a preview, such as [VS Code](/tools/vs-code/) (`Ctrl+Shift+V`) or [Obsidian](/tools/obsidian/), or a chat or GitHub comment box.

**How it works:** each page is one short lesson. Type the examples as you go. The sidebar shows them all, and **Next** at the bottom of each page takes you to the next one.
